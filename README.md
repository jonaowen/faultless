# Faultless French

Part of the **Faultless** series (Faultless French, Faultless German, …). A Direct Instruction spoken-language app, modelled on Direct Instruction Spoken English (DISE). It is taught entirely in the target language, and it uses speech recognition to hear the learner's answers.

This is the prototype: French, Lesson 1 (following DISE Lesson 1).

Open it at https://jonaowen.github.io/faultless/ in Chrome and allow the microphone. On a phone, use **Add to Home screen**.

The tester panel (gear icon) shows:
- what the recogniser heard for every answer;
- first-time-correct figures;
- a downloadable log.
